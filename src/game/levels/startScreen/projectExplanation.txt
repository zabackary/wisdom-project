This project is written in TypeScript using HTML5 Canvas and a custom framework (reused from a project last year). It uses Rapier for physics simulations.
This project explores the themes of wisdom and meaninglessness in the problem of racial discrimination based on Proverbs and Ecclesiastes.
Disclosure: GitHub Copilot autocomplete (generative AI) was used in this project, based off my previous programming patterns. However, Copilot Edits and file generation were not used at all, and all architectual decisions were made by me, a human.
